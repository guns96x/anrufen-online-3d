# Місто Бенма (奔马城, Benma City) — Довідник та декодування

## Загальні відомості про сцену

- **ID сцени**: `120056`
- **Оригінальна назва**: `奔马城` (Місто Бенма / Galloping Horse City)
- **Файл карти**: `city\city-benmacheng.wim` (архів `private/A000BA0E/mapfile_city.godat`, запис `1009`, розмір 43 770 байтів)
- **Музика**: `alica_music.mid`
- **Розмір сітки**: 60 × 60 тайлів
- **Формат клітинки**: 12 байтів (3 шари по 4 байти uint32):
  - **Шар 0 (L0)**: Текстура землі/покриття (переважають 12 — ґрунт/трава, 13 — брукована дорога, 3085 — кам'яна площа)
  - **Шар 1 (L1)**: Об'єкти, будівлі та декорації
  - **Шар 2 (L2)**: Фізична колізія: `0` — вільний прохід (2192 клітинки), `1` — непрохідна перешкода/стіна (1408 клітинок)

## Сюжетна роль та перехід із Ґуаньліня

Після завершення початкового розслідування в Ґуаньліні (квести 80004 -> 80591 -> 80552 -> 80005 зі свідками 80006, 80010, 80012) сюжетна лінія продовжується через розкриття змови культистів (80544..80050) і завершується квестом **80051 «Королівський указ»** (`国王诏令`). Староста Ґуаньліня (50164) вручає гравцеві рекомендаційного листа та відправляє його до спецпосланця королівських лицарів (50188) у місто Бенма. Для визнання лицарями гравець має досягти щонайменше 8-го рівня.
